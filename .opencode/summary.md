# Cryptobingo — Anchored Summary

## Goal
- Complete admin panel frontend (7 screens), add multi-role dev login, fix pnpm build errors across the monorepo, fix Docker compose deployment, fix Antelope contract compilation, fix DUNES bootstrap and infra integration, implement off-chain metadata for gametypes (typed patterns + combinations), update openapi.yaml to v1.4.0.

## Constraints & Preferences
- TypeScript strict mode throughout all apps/packages
- Node >= 18, pnpm >= 8
- Compliance with Brazilian Lei 14.790/2023 (fixed-odds betting) and LGPD
- Frontend is React 18 + Vite 5 + Tailwind CSS v4 (CSS-first config, no tailwind.config.js). Wharfkit for wallet auth.
- Admin routing is state-based (`section` React state in App.tsx) instead of React Router
- Worker uses `rpcClient` from `@cryptobingo/blockchain-core`; `get_table_rows` overloads require `UInt64` for `lower_bound`/`upper_bound` since `@wharfkit/antelope` v1; `index_position` expects string enum (`'primary'`, `'secondary'`, ...)
- `redis` and `pg` are direct dependencies of worker-game-loop; `@types/redis` not needed (v4 ships TS types), `@types/pg` required
- `Buffer` is not available in Vite production build (browser) — replaced with `TextEncoder`
- Dockerfiles use `pnpm deploy --prod` to produce self-contained deployment directories for api-gateway and worker-game-loop
- CDT 4.1.1 removed `EOSIO_REFLECT` macro; Antelope action names are limited to 12 characters; CDT 4.x abigen does not detect `[[eosio::table]]` structs reliably — ABI was manually crafted but is now regenerated by eosio-abigen
- DUNES v4 uses `dune -- cleos ...` passthrough syntax; `dune --start` creates container with port `127.0.0.1:8888` and `127.0.0.1:8080`

## Key Decisions
- **`UInt64` re-export** — shared from `@cryptobingo/blockchain-core` (re-exports `@wharfkit/antelope`) instead of direct worker dependency.
- **`pnpm deploy --prod`** for Docker — produces self-contained `/app/deploy` with flat `node_modules`, avoids symlink issues.
- **ABI initially manual, now auto-generated** — CDT 4.x abigen originally output broken ABI (empty `tables: []`), so ABI was hand-crafted. Later `eosio-abigen` began working correctly, so ABI is now regenerated automatically.
- **api-gateway port 8083** — avoids DUNES container's `127.0.0.1:8080` binding.
- **`dunes_container` on compose network** — worker connects via `http://dunes_container:8888` instead of `host.docker.internal`.
- **Single source of truth** — `init_dev_env.sh` propagates ALL env vars to all `.env` files, plus `.dev.env` aggregate.
- **Off-chain metadata** — `GametypeMetadata` MongoDB model stores `rules_extended` (typed patterns) + `combinations` (clause-based compound patterns) complementing on-chain `gametypes` table.
- **Dev mode auto-promoção** — `profileController` promotes known admin wallets (`gameadmin11`, `contractad1`) to `role: 'admin'` when `VERIFY_KEY_ONCHAIN !== 'true'`.
