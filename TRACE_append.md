- **2026-05-25**: (BugFix-Auth) Correção do fluxo de autenticação JWT. Causa raiz: `session.sign({ digests })` não existe como API pública no Wharfkit — o SDK sempre faz `getInfo()` no nó RPC antes de assinar, causando `ERR_CONNECTION_REFUSED` em `127.0.0.1:8888`. Solução: dois modos distintos de assinatura selecionados automaticamente. Modo dev: `PrivateKey.from(devKey).signDigest(SHA256(nonce))` — zero chamadas RPC. Modo produção: transação `eosio.null:nonce` com `broadcast:false` via proxy Vite. O servidor distingue os modos pela presença de `transactionPayload` no body. Arquivos alterados: `frontend/src/hooks/useAuth.ts` (dois modos + detecção automática de plugin), `frontend/src/services/api.ts` (reescrito limpo, `verifyAuthChallenge` com `transactionPayload` opcional, `public_key` corrigido), `api-gateway/src/controllers/authController.ts` (suporte a ambos os modos: digest puro via `Checksum256.hash(nonce)` e transação via `transaction.id`; validação de nonce no banco movida para antes da verificação criptográfica).
