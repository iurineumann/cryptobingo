# Product

## Register

product

## Users

**Players**: Crypto gamers on WAX blockchain. Context: real-money bingo with crypto rewards. Primary task: buy tickets, watch draws, claim wins, track progression. Expect fast, game-like UI with clear feedback.

**Admins**: Platform operators. Context: manage rooms, gametypes, patterns, drops, compliance. Primary task: configuration and monitoring.

**Sponsors**: B2B partners running promotional rooms. Context: configure campaigns, allocate NFT drops, track ROI.

## Product Purpose

On-chain BINGO platform (GameFi) on WAX/Antelope. RTP 85% / GGR 15%. Combines traditional bingo with blockchain transparency, NFT mechanics (discounts, boosts, burns), progression systems (XP/levels/tiers), and social features (presence, reactions, chat). Success looks like: players engaged daily via XP/levels, sponsors running active campaigns with verifiable on-chain payouts, games running autonomously via worker orchestration.

Latest: GameRoom UX phased rollout (cinematic reveal, near-miss, match stats, social), ReplayRoom refactored, deep link auth fixed, B2B campaign lifecycle complete with E2E coverage.

## Brand Personality

Dark, confident, playfully premium. Violet-gold palette. "Neon-lit casino meets crypto dashboard." 3 words: bold, radiant, sharp.

## Anti-references

- No SaaS-cream/beige backgrounds (already dark theme)
- No generic bootstrap admin panels
- No cartoon/gamey aesthetics (not Roblox)
- No overdone glassmorphism
- No purple gradient backgrounds (violet is brand but used sparingly)

## Design Principles

1. **Dark by default, not dark by afterthought** — the dark theme is the canvas, not a mode. Light mode is a courtesy.
2. **State is visible** — every game state, every XP change, every transaction has a clear visual feedback.
3. **Progression is a reward** — XP/level UI should feel like unlocking, not grinding.
4. **Data is live** — on-chain state drives UI, not stale cache. Show freshness.
5. **Mobile-first bingo** — the core gameplay fits a phone screen. Admin can sprawl.

## Accessibility & Inclusion

- WCAG AA minimum (4.5:1 body text contrast against dark surfaces)
- Reduced motion support for game animations (ADR-031)
- i18n in 3 locales (pt-BR default, en-US, zh-CN)
- Sound effects optional (default off) — never required for gameplay
