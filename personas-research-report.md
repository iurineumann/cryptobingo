# Web Personas & Research Report — CryptoBingo Landing Page

## 1. Analysis Frameworks (Most Applicable to GameFi/Bingo)

### Priority Ranking for CryptoBingo:

| Framework | Why Applicable | Priority |
|-----------|---------------|----------|
| **BJ Fogg Behavior Model (B=MAP)** | Core: Motivation + Ability + Prompt. CryptoBingo needs users to: 1) understand WAX/crypto (Ability), 2) want to win (Motivation), 3) click "Play Now" (Prompt). Critical for reducing friction in crypto onboarding. | **P0** |
| **LIFT Model** | 6 factors: Value Prop, Relevance, Clarity, Anxiety, Distraction, Urgency. Every factor maps directly: crypto-inexperienced users have high Anxiety, WAX transactions create Distraction, game timers create Urgency. | **P0** |
| **Cialdini's 6 (7) Principles** | Social Proof (testimonials, win amounts), Scarcity (limited rounds), Authority (WAX blockchain, audited contracts), Reciprocity (free demo credits), Liking (community), Commitment (free account). | **P0** |
| **Nielsen's 10 Heuristics** | System Status (tx confirmation), Real-world match (calling it "bingo", not "on-chain settlement"), User Control (undo bets), Consistency, Error Prevention (prevent double-bet). | **P1** |
| **TRACE Framework** (Articos 2026) | Traffic Relevance Audience Copy Experience — quick 1-day audit structure for any landing page. | **P1** |
| **MECLABS Conversion Heuristics** | 10K+ experiments. Value Prop formula: C=4m+3v+2(i-f)-2a. Quantifies conversion probability. | **P1** |
| **HEART Framework (Google)** | Happiness (NPS), Engagement (time, pages), Adoption (wallet connects), Retention (return plays), Task Success (purchase flow). | **P2** |
| **AIDA Copywriting** | Attention→Interest→Desire→Action. Hero section structure for crypto-bingo landing. | **P1** |
| **PAS Copywriting** | Problem→Agitate→Solution. Best for cold-traffic: "Tired of zero-RNG games? Bingo on-chain proves fairness." | **P1** |

### Why LIFT + Fogg + Cialdini dominate for CryptoBingo:

- **Crypto = high anxiety.** LIFT's Anxiety factor is the #1 blocker. Users fear: wallet drain, rug pulls, complex gas fees, losing private keys. Landing must pre-emptively address.
- **Crypto = low ability (for new users).** Fogg's Ability dimension. Need WAX wallet? Need to buy tokens? Need to understand "staking"? Each step drops conversion.
- **Crypto = community-driven.** Cialdini's Social Proof + Liking matter more here than traditional finance.

## 2. User Personas for CryptoBingo

### Persona 1: The Casual Gamer ("Lucky Luísa")
- **Age:** 28-45
- **Crypto exp:** None to minimal (has heard of Bitcoin)
- **Gaming:** Plays mobile games, Facebook games, occasional lottery
- **Motivation:** Fun, entertainment, possibility to win. Low stakes.
- **Pain points:** "Crypto is scary." "I don't understand wallets." "Do I need to pay to play?"
- **Landing needs:** "Free to try." No wallet required at first. Clear R$ (BRL) values, not token amounts. Social proof via "real people winning."
- **Channels:** Facebook, Instagram, YouTube, Google Search "jogar bingo online"
- **Conversion trigger:** Free credits to test, simple Google/Facebook login, Portuguese language

### Persona 2: The Crypto Enthusiast ("Trader Thiago")
- **Age:** 22-38
- **Crypto exp:** High. Holds ETH/SOL/WAX. Knows DeFi, NFTs, staking.
- **Gaming:** Plays Web3 games (Axie, Splinterlands, Pixels)
- **Motivation:** Earn yield on crypto. Interesting use case. "WAGMI" mindset.
- **Pain points:** "Is this legit?" "What's the RTP?" "Can I audit the contract?" "Low liquidity concerns."
- **Landing needs:** Technical specs: RTP 85%, contract address, audit links, on-chain proof, token economics. Wallet connect button prominent.
- **Channels:** Twitter/X, Discord, Telegram, CoinGecko, DeFi Llama
- **Conversion trigger:** Contract verified. High RTP. Token incentives. Referral rewards.

### Persona 3: The Serious Gambler ("Bettor Bruno")
- **Age:** 35-60
- **Crypto exp:** Low to medium. Uses crypto for deposits/withdrawals.
- **Gaming:** Online poker, sports betting, casino, traditional bingo halls
- **Motivation:** Consistent winning. Trust. Speed of withdrawals. Bonuses.
- **Pain points:** "Crypto is volatile." "I want fast cashouts." "What's the house edge?" "Provably fair?"
- **Landing needs:** Deposit bonus. VIP program. Clear RTP. Fast withdrawal claims. Responsible gambling info.
- **Channels:** Google Ads (casino/bingo keywords), affiliate sites, email lists
- **Conversion trigger:** Welcome bonus, first deposit match, VIP perks, big jackpot amounts

### Persona 4: The Community Builder ("Guild Leader Gabi")
- **Age:** 25-40
- **Crypto exp:** Medium to high. Active in Discord, runs a guild/community.
- **Gaming:** Web3 games, manages multiple accounts, referral source
- **Motivation:** Grow community. Earn referral commissions. Exclusive perks for members.
- **Pain points:** "How do I onboard my members?" "What's the referral system?" "Do I get a custom room?"
- **Landing needs:** Referral program details. Community/channel links. Guild rooms. Group discounts.
- **Channels:** Discord, Telegram, Twitter, Medium
- **Conversion trigger:** Generous referral % (revshare), custom room, community dashboard, whitelabel options

### Persona 5: The Investor/Whale ("Capital Carla")
- **Age:** 35-55
- **Crypto exp:** High. Deep pockets. Token holder/investor.
- **Gaming:** Minimal. Sees this as a business.
- **Motivation:** Token price appreciation. Protocol revenue. GGR share.
- **Pain points:** "What's the treasury?" "How are fees distributed?" "What's the burn mechanism?" "Team locked tokens?"
- **Landing needs:** Tokenomics page. Audit reports. Team info. Roadmap. Revenue dashboard.
- **Channels:** Crypto Twitter, CoinMarketCap, Medium, Dune Analytics, investor groups
- **Conversion trigger:** Strong fundamentals, token utility, staking yields, buyback/burn

### Persona 6: The Curious Newcomer ("Newbie Naldo")
- **Age:** 18-70
- **Crypto exp:** Zero. Heard about crypto, never used.
- **Gaming:** Traditional bingo at church/community center. Casual.
- **Motivation:** "My friend plays this." "Saw on TV/internet." "Looks fun."
- **Pain points:** "What is WAX?" "I don't understand any of this." "Why do I need a wallet?" "How do I get money in?"
- **Landing needs:** Simple explainer (3 steps: 1. Create Wallet, 2. Buy Tokens, 3. Play Bingo). Absolute zero jargon. Fiat onramp. Tutorial video.
- **Channels:** Google Search, YouTube, TikTok, friend referral, TV ad
- **Conversion trigger:** "Play for free." No wallet required initially. Portuguese-first experience. Tutorial gamified.

## 5. Testing Methodology (A/B Test Priority Order)

### What to test FIRST (highest impact per test):

1. **Headline variants** (15-60% lift potential)
   - Control: current headline
   - Variant A: Benefit-focused ("Win Crypto Playing the Game You Love")
   - Variant B: Curiosity gap ("Your Grandma Played This. Now It's On-Chain.")
   - Variant C: Numbers-driven ("R$ 50,000+ in Prizes This Week")

2. **CTA button copy** (202% lift potential per Unbounce)
   - Control: "Play Now"
   - Variant A: "Get Free Credits"
   - Variant B: "Try Bingo Free"
   - Variant C: "Claim Your Free Card"

3. **Social proof placement** (up to 34-340% lift)
   - Above fold vs below fold
   - Logos vs testimonials vs numbers
   - Live win counter

4. **Form/wallet connect flow steps** (10% per field removed)
   - 1-click vs 2-click vs full signup
   - Guest mode vs wallet required

5. **Mobile layout** (60%+ traffic is mobile)
   - Sticky CTA vs bottom of page
   - Image vs no-image hero

### A/B Testing Rules:
- One variable per test
- Minimum 1,000 visitors per variant
- Run minimum 2 weeks (1 full business cycle)
- 95% statistical significance required
- Segment by: device (mobile/desktop), traffic source (organic/paid/social), crypto exp (new/returning)

## 6. Heuristic Evaluation (Nielsen — Specific to CryptoBingo)

| Heuristic | CryptoBingo Application | Risk Level |
|-----------|------------------------|------------|
| **1. Visibility of system status** | Wallet connection feedback, transaction pending/completed alerts, draw countdown timer | **HIGH** — Users MUST know: is my bet placed? Is drawing? Did I win? |
| **2. Match between system and real world** | "Bingo card" not "NFT ticket", "Prize pool" not "GGR allocation", "Buy credits" not "Swap tokens" | **HIGH** — Crypto jargon kills casual conversion |
| **3. User control and freedom** | "Cancel order" before tx signed. "Exit" wallet connect flow. "Play again" after round. Undo button. | **MEDIUM** |
| **4. Consistency and standards** | CTA colors consistent. Wallet connect icon standard (WAX Cloud Wallet). Terms match across pages. | **MEDIUM** |
| **5. Error prevention** | Prevent double-bet. Warn before signing transaction. Validate minimum balance before allowing play. Auto-detect insufficient funds. | **CRITICAL** — On-chain errors cost real money |
| **6. Recognition not recall** | Show recent providers, favorites, saved preferences. Don't make user re-enter wallet address. | **LOW** |
| **7. Flexibility and efficiency** | Power-user: keyboard shortcuts, auto-buy, batch actions. Novice: guided play. | **MEDIUM** |
| **8. Aesthetic and minimalist design** | Above-fold: 1 headline, 1 subhead, 1 CTA. No clutter. Progressive disclosure for details. | **HIGH** — Crypto sites notoriously cluttered |
| **9. Help users recognize, diagnose, recover from errors** | Failed TX? Show reason clearly: "Network fee too low" not "Error 32603". Insufficient balance? Show cost breakdown. | **CRITICAL** — Users WILL see errors in wallet/tx flows |
| **10. Help and documentation** | FAQ: "How do I play?", "How do I withdraw?", "What is WAX?" Optional onboarding overlay. Video tutorial. | **HIGH** — New users need hand-holding |

## 7. Copywriting Frameworks — Section Map for CryptoBingo Landing

### Section-by-Section Framework Assignment:

| Section | Framework | Rationale |
|---------|-----------|-----------|
| **Hero** | AIDA (Attention) | "Online Bingo. On-Chain. 85% RTP." Hook in 5 words |
| **How It Works** | FAB (Features→Advantages→Benefits) | "Blockchain ensures every draw is random" = feature. "No rigged games" = advantage. "You always know the odds" = benefit |
| **Why Us** | AIDA (Desire) + Social Proof | Community stats, win amounts, testimonial |
| **FAQ** | PAS (Problem→Agitate→Solution) | "Is this safe?" → "Crypto scams are everywhere" → "We use audited WAX smart contracts" |
| **CTA Section** | Urgency + Scarcity | "Only 50 cards left this round. Join now." |
| **For Crypto Users** | Technical depth, ABI, contract, audit links | Jump to technical section via anchor link |
| **For New Users** | BAB (Before→After→Bridge) | "Before: boring online bingo, unknown fairness. After: on-chain bingo you can verify. Bridge: try it free." |

### Best Framework for Each Audience:
- **Casual/Newbie:** BAB — show transformation from confused to winning
- **Crypto native:** Features — they want specs first
- **Gambler:** PAS — hit pain points (slow withdrawals, rigged games), agitate, solve
- **Community:** Social Proof + Reciprocity — invite rewards, referral bonuses

## 8. Analytics Framework (Funnel + KPIs)

### Full Funnel Stages:

```
Awareness → Interest → Consideration → Conversion → Activation → Retention → Advocacy
```

### Metric Tree:

| Stage | KPI | Tool | Target |
|-------|-----|------|--------|
| **Awareness** | Sessions, Impressions, CTR | GA4, GTM | CTR > 3% |
| **Interest** | Time on page, Scroll depth (50%), Bounce rate | GA4, Hotjar | Bounce < 40% |
