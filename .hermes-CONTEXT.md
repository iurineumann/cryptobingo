# CONTEXT — fix/c7-showing-shown (semântica locked → drawn → showing → shown)

## Objetivo
Corrigir bug em que o worker pula de `locked` (on-chain) direto para `drawn` (on-chain) e esquece
de fazer o slow reveal (nosso lado). Jogo 1784390752148 (sala 12) foi para `drawn` sem mostrar
o sorteio na tela.

## Modelo (decisão usuário 2026-07-18)
`... → locked → drawn → showing → shown → ...`
- `locked` (on-chain): vendas encerradas.
- `drawn` (on-chain): bolas sorteadas de UMA vez pelo contrato (oráculo). Fim da responsabilidade on-chain.
- `showing` (NOSSO LADO / worker): slow reveal em andamento. Worker publica `ball_drawn`.
- `shown` (NOSSO LADO / worker): reveal completo SEGUNDO AS REGRAS DO GAMETYPE (não fixo 75).
  Aí roda evaluator → paga → notifyGameEnded → onGameResolved.
- `archived` (on-chain, após closegame).

Contrato NÃO muda. showing/shown são puramente lógicos (worker+frontend), comunicados via WS.
