Post lido. Conceitos chave do agent teams no OpenCode:
Arquitetura:
Lead spawns teammates com contexto próprio
Inbox JSONL (append-only, O(1)) + session injection (event-driven, no polling)
Fire-and-forget com auto-wake (lead acorda ao receber msg)
Comunicação full mesh (peer-to-peer, não só via lead)
9 ferramentas dedicadas: team_create/spawn/message/broadcast/tasks/claim/approve_plan/shutdown/cleanup
Duas state machines: member lifecycle (5 states) + execution (10 states)
Isolamento:
Sub-agents sem acesso a team messaging (deny rules + tool hiding)
Recovery manual pós-crash (intencional, previne runaway)
Diferença chave vs Claude Code:
JSONL vs JSON array → O(1) write vs O(N)
Auto-wake vs polling
Multi-provider no mesmo time
Delivery receipts (best-effort)
O que falta: backpressure, cross-team communication, self-healing

CB-ContextOS: Adaptation Proposal
ContextOS ported for CryptoBingo. Core mechanism: experimental.session.compacting hook (official, documented at opencode.ai/docs/plugins#compaction-hooks).

How it survives compaction
Plugin registered on experimental.session.compacting hook
Before compaction, plugin reads SESSION_GUARD.md from disk
Injects content into output.context (official API)
After compaction, model sees guard content and resumes
Guard is a ~25-line file with: phase, files changed, decisions, blockers, next action, constraints. Small enough to fit in compaction prompt without bloating.
What goes where

Plugin code (for approval):
import { readFileSync, existsSync } from 'fs';
import { join } from 'path';

const GUARD_PATH = join(process.cwd(), '.contextos', 'guard', 'SESSION_GUARD.md');

export const ContextOSGuard = async ({ project, client, $, directory }) => {
  return {
    'experimental.session.compacting': async (_input, output) => {
      if (!output?.context) return;
      try {
        if (existsSync(GUARD_PATH)) {
          output.context.push(
            `## Session Guard (from .contextos/guard/SESSION_GUARD.md)\n${readFileSync(GUARD_PATH, 'utf-8')}`
          );
        }
      } catch {}
    },
  };
};

export default ContextOSGuard;
